# 🎂 Напоминания о днях рождения

Offline-first PWA приложение на Vue 3 + Tailwind CSS + DaisyUI для отслеживания и напоминания о днях рождения контактов.

## Возможности

- **📱 Импорт контактов** — через Web Contacts API (Android Chrome) импортирует имена из телефонной книги
- **🎉 Уведомления** — напоминает за N дней до дня рождения и в сам день рождения
- **📅 Обратный отсчёт** — показывает сколько дней осталось до дня рождения
- **🎂 Возраст** — автоматически вычисляет сколько лет исполняется
- **💾 Экспорт/Импорт JSON** — резервное копирование и перенос данных
- **🌙 Тёмная тема** — переключатель светлой и тёмной темы
- **📴 Offline-first** — все данные хранятся локально в IndexedDB, статика кэшируется Service Worker

## Технологии

| | |
|---|---|
| Фреймворк | Vue 3 (Composition API) |
| Сборка | Vite |
| Стили | Tailwind CSS v4 + DaisyUI v5 |

## Быстрый старт

```bash
# установка зависимостей
make setup
# или: npm install

# запуск в режиме разработки
make dev
# или: npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## Сборка для production

```bash
make build
# или: npm run build
```

Собранные файлы в папке `dist/`.

## Деплой

Приложение полностью статическое (HTML + JS + CSS). Подходит для любой платформы:

### GitHub Pages

```bash
npm run build
npx gh-pages -d dist
```

### Netlify / Vercel

Подключите репозиторий — платформа自动 определит Vite-проект и соберёт его.

Или сделайте деплой вручную:

```bash
npm run build
npx netlify deploy --prod --dir=dist
```

### Docker

```dockerfile
FROM nginx:alpine
COPY dist /usr/share/nginx/html
EXPOSE 80
```

### Любой static hosting (Firebase, Cloudflare Pages, Surge и т.д.)

Просто загрузите содержимое папки `dist/` на хостинг.

## Как пользоваться

1. **Первый запуск** — приложение предложит импортировать контакты из телефонной книги (на Android Chrome) или добавить вручную
2. **Главный экран** — контакты сгруппированы:
   - 🎉 Сегодня — именинники сегодня
   - 📅 На этой неделе — ближайшие 7 дней
   - 🗓 В ближайший месяц — до 30 дней
   - Все контакты — остальные
3. **Добавление даты** — нажмите на имя контакта в блоке «У N контактов не указана дата» или через кнопку ➕
4. **Настройки** — импорт контактов, включение уведомлений, выбор периода напоминания, экспорт/импорт JSON, смена темы
